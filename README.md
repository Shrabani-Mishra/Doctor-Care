# 🩺 Doctor-Care - Doctor Appointment Booking Platform

A modern, responsive doctor appointment booking website built with React + Tailwind CSS. Book appointments with 100+ trusted doctors in 60 seconds.

🔗 **Live Demo:**
🔗 **GitHub:** https://github.com/Shrabani-Mishra/Doctor-Care

![Doctor-Care Banner](https://via.placeholder.com/800x400?text=Doctor-Care+Preview)

## ✨ Features

- **Find Doctors:** Filter by speciality (General Physician, Dermatologist, Pediatrician, etc.)
- **Smart Booking:** Check doctor availability & book slots instantly
- **Responsive Design:** Works perfectly on Mobile, Tablet & Desktop
- **Context API:** Global state management for doctors, appointments
- **Modern UI:** Glassmorphism, hover animations, premium look inspired by Apollo & Practo

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite), React Router DOM
- **Styling:** Tailwind CSS
- **State:** Context API
- **Icons:** Custom SVG + Assets
- **Mock Data:** Centralized dummy data (API-ready structure)
